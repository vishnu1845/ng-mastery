Chaining: each pipe gets the result of the one before

In the template Shown on the page
released | date: 'MMMM y' | uppercase {{ released | date: 'MMMM y' | uppercase }}
title | slice: 0 : 15 | uppercase {{ title | slice: 0 : 15 | uppercase }}
title | uppercase | slice: 0 : 7 {{ title | uppercase | slice: 0 : 7 }}

A pipe binds tighter than ? :

In the template Shown on the page
isPro ? 'pro plan' : 'free plan' | uppercase {{ isPro() ? 'pro plan' : ('free plan' | uppercase) }}
(isPro ? 'pro plan' : 'free plan') | uppercase {{ (isPro() ? 'pro plan' : 'free plan') | uppercase }}

Without brackets, the pipe belongs to the last value only. Tick the box and the first row is no longer in capitals.
