## Definition

**Angular** is an **open-source framework** developed and maintained by **Google**, based on **TypeScript**, used to build static as well as dynamic **Single Page Applications (SPA)**.

## 2026 update

Modern Angular (v22) is built with **standalone components** and **signals**. New apps run **without Zone.js**, and components use **OnPush** change detection by default.

## Key terms

- **Open source**: free to use, anyone can read and contribute to the code (MIT license).
- **Framework**: a complete set of tools with its own rules and structure to build full apps.
- **TypeScript**: JavaScript plus static types, so we catch errors while coding, not at runtime.
- **SPA**: the app loads once, then updates the page without full reloads.

## Say it like this

"Angular is an open-source framework by Google, built on TypeScript, that we use to build Single Page Applications. So instead of reloading the whole page on every click, Angular loads the app once and then updates only the parts that change. And in modern Angular, we build everything with standalone components and signals, which keeps the code simple and the app fast."
