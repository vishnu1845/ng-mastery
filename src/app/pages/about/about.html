About this project

NgMastery is an open-source Angular 22 playground. It covers the framework in 52 topics, and every lesson has a live demo, the real source code and a short spoken answer for interviews.

Stack

Framework Angular 22 (standalone, signals, zoneless, SSR + prerender)
Language TypeScript 6 in strict mode, strict templates
Styling Our own design system in SCSS with CSS variables (dark, light, system)
Code highlighting Shiki with the Angular template and TypeScript grammars
Testing Vitest through the Angular CLI
Quality angular-eslint and Prettier
